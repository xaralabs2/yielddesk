Product: YieldDesk

Platforms:

Database: PostgreSQL
Cache/Queue: Redis
1. PRODUCT VISION

YieldDesk is a capital allocation system that continuously determines:

“Where should capital be deployed right now to maximize yield under defined rules?”

It combines:

Market signals (rates, deals)
Portfolio state
Deterministic rules

To produce:

Clear actions
Portfolio insights
Timely alerts
2. CORE PRINCIPLE

The system is decision-first, not data-first.

All features must support:

Decision → Allocation → Monitoring → Reallocation

3. CORE DECISION ENGINE
Base Rule Set
if (cp_rate >= 18) return "INVEST_CP";
if (bond_yield >= 17) return "LOCK_BONDS";
return "HOLD_MMMF";
Extended Decision Inputs
CP rates (multiple issuers)
Bond yield curve (tenors)
User portfolio allocation
Liquidity level
Time to maturity (existing CPs)
Extended Output
{
  "action": "INVEST_CP",
  "amount": 5000000,
  "reason": "CP rate exceeds threshold",
  "confidence": "HIGH"
}
